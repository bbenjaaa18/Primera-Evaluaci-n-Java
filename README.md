1. <popovertarget>
	Función: Es una etiqueta moderna que facilita la creación de ventanas emergentes sin necesidad de JavaScript.  
	Uso en mi currículum: Agregué un botón que muestra un mensaje emergente con información sobre una motivación para trabajar nuestras habilidades.
	
<section id="motivacion">
        <button popovertarget="mensaje"> ¡Inspírate!</button>
        <div id="mensaje" popover>
            <h3>¡Nunca dejes de aprender! </h3>
            <p>Las habilidades que adquieres hoy serán las que te abrirán puertas mañana.</p>
            <p> Consejo: Dedica al menos 30 minutos al día a aprender algo nuevo. ¡Tú puedes!</p>
            <button popovertarget="mensaje">Cerrar</button>
        </div>
    </section>


2. <iframe>
 La etiqueta <iframe> en HTML se utiliza para incrustar contenido externo dentro de una página web. Permite mostrar otros documentos HTML, videos de plataformas como YouTube, mapas interactivos y más.
 Uso en mi currículum:Yo utilize para simular un video de Youtube como proyecto propio.

	<iframe width="560" height="315" 
            src="https://www.youtube.com/embed/K-c_t9fshGU" 
            title="Proyecto de Desarrollo Web"
            frameborder="0" 
            allowfullscreen>
        </iframe>



3. <footer>
La etiqueta <footer> en HTML se utiliza para definir el pie de página de un documento o sección. Generalmente, contiene información como derechos de autor, enlaces a políticas, información de contacto o navegación adicional.
Uso en mi currículum:Yo lo utilize para agregar mi nombre completo como desarrollador y con mi email.

    <footer>
        <p>© 2024 Benjamin Mella Andrade. Todos los derechos reservados.</p>
        <p>Contacto: <a href="mailto:Benjamin123@gmail.com">Benjamin123@gmail.com</a></p>
    </footer>
